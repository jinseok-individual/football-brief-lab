# 데이터 규칙 — 국내외 축구 이슈 브리핑

## 1. 칸
| 이름 | 형식 | 필수 |
|---|---|---|
| 제목 | 글자 | 필수 |
| 언론사 | 글자 | 필수 |
| 날짜 | YYYY-MM-DD | 필수 |
| 구분 | 국내 또는 해외 | 필수 |
| 링크 | https://로 시작 | 필수 |
| 합성 | 합성이면 Y, 실제 기사면 비움 | 선택 |

## 2. 중복
- 같은 항목: 제목이 같으면 같은 기사로 본다.
- 비교 전 맞추기: 앞뒤 공백 제거, 연속 공백은 1칸으로, 영문은 소문자로 바꾼다.
- 남기는 것: 날짜가 더 최근인 것. 날짜도 같으면 먼저 들어온 것.
- 언론사가 달라도 제목이 다르면 다른 기사로 본다.
- 같은 사건을 다른 언론사가 쓴 기사는 하나로 본다

## 3. 정렬
- 1차: 날짜 최신순
- 2차: 국내 먼저 정렬 
- 날짜가 같으면 2차 기준으로 정한다. (날짜가 빈 항목은 제외되므로 정렬에 오지 않는다.)
- 

## 4. 제외 (이유와 함께 뺀다)
- 필수 칸이 비어 있음
- 날짜 형식이 YYYY-MM-DD가 아님, 또는 달력에 없는 날짜
- 날짜가 기준일보다 미래이거나, 기준일 7일보다 더 지남 (범위 밖)
- 구분이 국내/해외가 아님
- 링크가 https://로 시작하지 않음

기준일: 화면에 표시하는 날짜. 
확인 공식: 원천 N = 제외 X + 중복 Y + 표시 K
