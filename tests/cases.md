# 검사표 — 데이터 규칙 검사 10줄

- **기준일 2026-11-22 고정.** 오늘 날짜가 아니라 이 날짜로 계산하므로 내일 돌려도 같은 결과가 나온다. (범위: 기준일 포함 7일 전까지)
- 규칙은 docs/data/RULES.md. 이 표는 그 규칙을 작은 입력으로 시험하는 정답지다.
- 입력은 `"제목"@날짜` 형식이고 여러 건은 `;`로 나눈다. 따옴표 안의 공백(끝 공백 포함)도 그대로 센다.
- 입력에서 적지 않은 칸(구분·언론사·링크)은 구분=해외, 언론사=테스트, 링크=https://example.com/t, 합성=비움으로 둔다.
- 기대 처리는 입력 순서대로 적는다. 건수는 원천/제외/중복/표시 순서이고 원천 = 제외 + 중복 + 표시여야 한다.

|---|---|---|---|---|---|---|
| 1 | 끝 공백만 다른 제목 | `"서울 블루 FC, 홈 개막전 역전승"@2026-11-21 ; "서울 블루 FC, 홈 개막전 역전승 "@2026-11-21` | 표시 ; 중복 | 2/0/1/1 | 서울 블루 FC, 홈 개막전 역전승 | 공백을 맞추면 같은 제목이고 날짜도 같아 먼저 들어온 것을 남김 |
